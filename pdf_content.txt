■  01 — INTRODUCTION
What is RahatLink?
RahatLink is an intelligent disaster relief platform that connects warehouses and NGOs through real-time location
data, verified disaster information, and smart allocation logic. It ensures efficient, transparent, and prioritized
distribution of essential supplies during emergencies.

■  03 — SOLUTION OVERVIEW
How RahatLink Solves the Problem
RahatLink provides a unified platform that addresses every gap in the current disaster relief ecosystem through five
core pillars:
◆
Verified Disaster Identification
A dedicated News Page pulls confirmed disaster updates, ensuring only legitimate zones receive priority status.
◆
Priority-Based Allocation
Disaster zones receive highest priority. Resources flow to the most critical areas first using urgency-based
sorting.
◆
Live Map Visualization
All warehouses and camps are displayed in real-time on an interactive map with clickable markers and route
lines.
◆
Distance-Based Intelligent Routing
The system identifies the nearest warehouse to each disaster camp and calculates optimal supply routes.
◆
Manual + Automated Distribution
Coordinators can manually select or trigger the automated optimization engine for system-wide allocation.
■  04 — DISASTER VERIFICATION SYSTEM
The News Page is the cornerstone of RahatLink's integrity. It acts as a real-time gate that only allows confirmed
disaster zones to enter the priority pipeline, preventing misuse of limited resources.

■  12 — ALGORITHM LOGIC
Smart Allocation Algorithm
The optimization engine uses a priority-weighted greedy algorithm that sorts camps by disaster status and urgency,
then matches each camp with the nearest warehouse that has sufficient stock.
Step 1
Load &
Classify
Load all camps. Flag disaster zones (verified via News Page).
Mark urgency levels.
Step 2
Priority Sort
Sort camps: (1) Disaster zones first, (2) Urgency level
descending, (3) Alphabetical tie-break.
Step 3
Nearest
Warehouse
For each camp, calculate Haversine distance to all warehouses
with available stock.
Step 4
Greedy
Allocation
Allocate from the nearest warehouse. Deduct from warehouse
inventory. Mark need as fulfilled or partial.
Step 5
State Update
After all allocations, update database. Return allocation plan for
display.

■  14 — UI/UX DESIGN PRINCIPLES
Design Philosophy
◆
Dark Theme
Deep #0D1117 background with card panels at #161B22 reduces eye strain during prolonged emergency
operations.
◆
Clean Spacing
Generous padding and white space ensure readability under stress. No cluttered elements.
◆
Card-Based Layout
Information organized in discrete cards makes scanning quick. Each card has a single clear purpose.
◆
Visual Hierarchy
Font sizes, colors, and weight guide the eye from most to least critical information.
◆
Interactive Feedback
Every action produces visible feedback: button states, loading spinners, success toasts.
◆
Minimal & Intuitive
No training required. Field workers and NGO coordinators can operate the system immediately.
