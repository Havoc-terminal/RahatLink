# RahatLink - Frontend Client

React + Vite frontend for the RahatLink Disaster Relief Inventory Optimizer platform.

## Features
- **11 Modular Views:** Landing page, role selection, location setup, victim emergency portal, interactive map, warehouse inventory panel, NGO requests panel, relief distribution tracking, greedy optimization, verified news alerts, and analytics dashboard.
- **Geospatial Mapping:** Interactive map visualization with Leaflet and React-Leaflet.
- **Multilingual Support:** English, Hindi, and regional language switching.
- **Responsive Design:** Built with Tailwind CSS.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
